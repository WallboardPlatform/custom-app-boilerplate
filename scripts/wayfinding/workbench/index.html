Route network

1. Confirm pedestrian space

Choose one source for this floor. The route builder uses only the selected source and preserves the other draft for later.

Blocked areas subtract planters, furniture, voids, or other no-go zones from the drawn pedestrian space.

Detect from floor colorOptional shortcut for flat-color plans

Pick a floor color to detect connected pedestrian space. Paint corrections only when the automatic selection misses or includes an area.

2. Build routes

Doors linked to rooms become route endpoints. The builder connects each endpoint to the nearest valid corridor centerline.

Replaces the current generated network, including manual route adjustments.

3. Manual adjustments

Select a segment to move its points, draw only the missing connection, or reposition a destination endpoint.
