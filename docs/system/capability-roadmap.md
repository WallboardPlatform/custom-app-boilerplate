# Capability Roadmap

Promote a candidate only when it adds reusable mechanics not already proven by a maintained example. User references and explicit concepts still lead visual design.

| Candidate | Data/media contract | Reuse before invention | Promotion gate |
|-----------|---------------------|------------------------|----------------|
| Product catalog | Promoted: editable `TABLE` products + independent File System images | `product-catalog` proves filename-stem lookup, platform cache, offline media preview, fallback, bounded transition, and live update | Extend generated projects for localization/category variants; do not turn the example into a universal catalog |
| Hall of fame | `TABLE` people/achievements; optional File System portraits | Recognition media handling and editorial text safety | Not promoted: overlaps `recognition-mosaic`. Promote only with a distinct timeline/filter/spotlight mechanic |
| Weather | Promoted: SDK `useWeather`/`WeatherService`; no datasource binding | `weather-window` proves platform refresh/cache ownership, defensive normalization, location-keyed preview, missing-media fallback, initial failure, and last-good stale state | Extend generated projects for device location or alternate compositions; never call vendor APIs or own credentials |
| PDF display/control | Promoted as opt-in `pdf`; file/folder sources and no datasource binding | `pdf-document-workspace` proves pinned PDF.js 2.3.200, isolated worker packaging, multiple documents, page ranges, single/continuous vertical/horizontal layouts, contain/fill/cover, lazy preload, outline/search/link/annotation/AcroForm layers, zoom, auto-scroll, download, commands, and cleanup | Keep PDF.js out of non-PDF apps. Sensor telemetry is available; true platform proof-of-display registration remains unavailable through the current SDK |
| Video playback/control | Promoted as opt-in `video`; direct File System file/folder or explicit JSON playlist, no datasource required | `lumen-media-program` proves checksum-pinned hls.js 0.7.9 plus native MP4/WebM, platform cache, packaged offline media, posters/WebVTT, autoplay/mute/volume, cover/contain/fill, repeat/seek/retry/advance, external commands, telemetry, and cleanup | Keep hls.js out of non-video apps. Platform native/external playback, synchronized screens, audio ducking, and proof-of-display remain SDK boundaries |

Next wayfinding increment: deterministic image/PDF/OCR destination extraction plus a local schema-aware authoring workbench that edits metadata, hit targets, entrances, and explicit edges; exports the annotated SVG, graph, review queue, and internal-datasource template. Prove the workflow by rebuilding Veszprem from `VeszpremTerkep.png`, then Foxwoods independently from `Foxwood 1.pdf`; do not reuse previously generated SVG geometry or topology.
